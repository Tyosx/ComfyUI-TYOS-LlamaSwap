# TYOS MediaPrompt v0.9.1

ComfyUI node for generating prompts using llama-swap multimodal models.

- Up to 9 images, 3 videos and 3 audio inputs; 12 connected media inputs total.
- Local system-prompt presets, model selection, token and duration settings.
- Optional GPU memory and model unloading controls.

Download the ZIP asset and extract it into ComfyUI/custom_nodes, then restart ComfyUI. Multimodal compatibility depends on the selected model and backend.
